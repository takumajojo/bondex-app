# 送り状（配送伝票）の印刷ガイド

Ship&co から発行される送り状（佐川・ヤマト）を、正しくA5で印刷するための手順。

## 結論：送り状はもともと A5・横向き

- Ship&co が返す送り状PDFのページサイズは **595 × 421 pt = 210 × 149 mm**。
  これは **A5 の横向き（ランドスケープ）** です（A5 = 148 × 210 mm）。
- つまり **サイズはすでにA5**。BondEx側で作り変えていません（Ship&co の既定フォーマットをそのまま配信）。
- 「A4で出てくる」ように見えるのは、**プリンターや印刷ダイアログの既定用紙がA4**になっていて、
  A5のPDFをA4用紙に拡大（またはA4の中央に配置）して印刷しているためです。
  PDF側からプリンターの用紙トレイを強制することはできないため、**印刷設定で用紙をA5にする**必要があります。

## A5で印刷する設定（PC・ブラウザ／PDFビューア共通）

印刷ダイアログで次の3点を設定します。

| 項目 | 設定値 |
|---|---|
| 用紙サイズ | **A5** |
| 印刷の向き | **横（ランドスケープ）** |
| 倍率 / 拡大縮小 | **100%（実際のサイズ / Actual size）** ※「用紙に合わせる/Fit」はOFF |

- **「用紙に合わせる（Fit to page）」は必ずOFF**。ONだと勝手に拡大縮小され、バーコードの寸法が変わって
  読み取り不良の原因になります。実寸（100%）が最も安全です。
- Chrome で開いて印刷する場合：詳細設定 →「用紙サイズ=A5」「倍率=100%」「余白=なし/既定」。
- Mac プレビュー / Acrobat の場合：用紙サイズをA5に、「実際のサイズ」を選択。

## 紙（A5用紙）のセットの向き

- **A5用紙をトレイのA5ガイドどおりにセットするだけでOK**。紙を手で回す必要はありません。
- 送り状の中身は横向きですが、**印刷ダイアログで「向き=横」を選べばプリンタードライバーが自動で回転**して
  合わせます（多くのプリンターはA5を短辺送りで給紙し、横向き印刷に自動対応）。
- 複合機（キヤノン/エプソン/ブラザー等）で手差しトレイを使う場合は、用紙ガイドをA5幅に合わせてセット。
  給紙方向（短辺/長辺）はプリンター任せで問題ありません。

## よくある質問

- **A4しか無い場合は？** A4用紙でも印刷は可能です。その場合は「用紙=A4／実寸(100%)」にすると、
  A4の中央にA5サイズのまま印刷されます（右側に余白が出るだけで、バーコード寸法は正しい）。
  A4に「合わせる」で拡大するとバーコードが大きくなりすぎることがあるため、拡大よりは実寸推奨。
- **ラベルシール（A5）に印刷したい？** A5ラベル用紙をセットし、上記の「用紙=A5／実寸」で印刷すれば
  そのまま貼れます。
- **サイズを変えたい（A6等）？** Ship&co の発行フォーマットに依存します。現状はA5固定（既定）。
  変更が必要なら Ship&co のラベル設定 or 発行APIの label 指定を要検討（app/api/shipandco/create/route.ts）。

## 根拠

- 実測: Ship&co 発行の送り状PDF = 595×421pt（210×149mm）= A5横。
- 発行コード: `app/api/shipandco/create/route.ts`（label_size 未指定＝Ship&co既定を使用）。
- 運営ダッシュボード/発行画面の「配送伝票」欄にも同じ趣旨の印刷ヒントを表示（app/operator/page.tsx: labelPrintHint）。
