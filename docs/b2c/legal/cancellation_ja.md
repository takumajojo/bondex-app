# キャンセル規定（旅行者の方向け）【原案 第3版】

> 原案 第3版（2026-11-05）。事業条件 D1・D2 を反映（`01_business_conditions.md`）。締切は利用規約 第2条4項の「受付締切」（集荷日の前日 18:30。D0 は 2026-11-05 確定）。弁護士の確認の前。公開しない。

この規定は、BondEx の旅行者向けの利用規約 第9条に基づき、予約の取消・返金の条件を定めるものです。時刻はすべて日本時間です。

## 1. お客様による取消

| 時期 | 方法 | 料金 |
|---|---|---|
| 受付締切（集荷日の前日の 18:30）まで | 予約の確認ページ（確定のメールのリンク）から取消 | 無料 |
| 受付締切の後、運送会社が集荷する前 | support@bondex.express へご連絡ください。当社が運送会社に取消を連絡します。運送会社への集荷の依頼の後は「取消のお申込み」となり、運送会社の確認の後に取消が確定します。確定するまで予約はそのままです | 集荷の前に取消が確定した場合は無料 |
| 運送会社が集荷した後 | 取消できません | 料金を請求します |

- 予約の確定の前（ホテルの確認中）の取消も無料です。
- 取消が確定した時は、メールでお知らせします。登録されたカードは当社の決済代行会社の記録から外します。

## 2. 当社による取消（無料）

次の場合、当社は予約を取り消します。料金はかかりません。
- 集荷元のホテルまたは配送先のホテルが手荷物を受け取れない場合
- 期限までにホテルの確認が取れない場合
- カードの登録が完了しない場合（カードの入力の画面を開いたまま 30分が過ぎた場合を含む）

## 3. 手荷物を預けなかった場合

集荷日の 11:00 までに手荷物が預けられず、運送会社が集荷できなかった場合、料金は請求しません。当社が状況を確認し、ご連絡します。その後、改めて集荷を手配して運送会社が集荷した場合は、通常どおり実際に集荷した個数で請求します。

## 4. 個数の違いと返金

- 料金は運送会社が実際に受け取った個数で計算します（利用規約 第5条）。
- 請求の後に、実際の個数が請求した個数より少なかったことが分かった場合は、差額を返金します。
- 返金はご登録のカードに行います。明細への反映には、カード会社によって数日から数週間かかります。返金した時はメールでお知らせします。

## 5. お届けの遅れ・集荷の後の事情

- お届けが遅れた場合の返金は一律ではなく、遅れの理由と実際の損害を確かめて個別に判断します。法令に基づく当社の責任や返金の義務を制限するものではありません。【L2】
- 運送会社が集荷した後は、取消はできません。
