作成: 2026-11-04。状態: **暫定の事業方針（たくまさんの採用 2026-11-04）**。規約の原案はこの条件で書いている。弁護士の確認の前・未公開。

根拠の種類: 「実装」= このリポジトリのファイル、「佐川」= 佐川急便の公開の約款・ページ（2026-11-04 に取得）と打合せの記録、「ヒアリング」= たくまさんへのヒアリング。

## D0. 受付締切（予約・旅行者による自分での取消）【要決定・最優先】

たくまさんの 2026-11-04 の指示では「旅行者の予約と自分での取消の締切は前日 17:00 を維持、18:30 は佐川の営業所への緊急の連絡の期限」。**ただし、統合ブランチの実装と同じ日の決定の記録は 18:30。** どちらに確定するか決めてもらう必要がある。

| 資料 | 内容 |
|---|---|
| 統合ブランチ `lib/pickup-cutoff.ts` | 「受付の締切 = 集荷前日 18:30 (JST) (2026-11-04 谷口さん決定)」。B2B・B2C 共通の関数 |
| 統合ブランチ `lib/b2c/bookability.ts`・`my-booking.ts`・`change-gate.ts` | 予約・取消・変更の判定は上の関数（18:30） |
| 統合ブランチ `sql/071_b2c_cutoff_1830.sql` | DB の確定の関数も 18:30 で判定・保存 |
| 統合ブランチ `lib/b2c/notify-templates.ts` | 旅行者へのメールの文面も 18:30（日英） |
| `~/JOJO/state/bondex.md`（2026-11-04 の行） | 「集荷前日 18:30 = 通常予約・直接変更の締切 / 19:00 = Biz-Logi 送信 / 20:00 = 佐川の締め。旧案（17:00 受付）は撤回」「段階C承認: B2C の新規予約・変更締切も B2B と同じ 18:30 に統一（谷口決定）」。根拠の文書は `MyClaudecode/docs/bizlogi-change-design-1900-20261104.md`・`docs/b2c-cutoff-1830-and-migration-20261104.md` |
| 佐川（`docs/sagawa/BondEx_Sagawa_BizLogi_Master_FULL_20261103.txt` 181・182） | 世田谷営業所の緊急の変更の受付は 18:30 まで・カスタマーサービスは 19:00 まで |
| B2C の旧ブランチ（`feat/b2c-mvp`） | 17:00（D03 確定 2026-11-02）。統合の時に 18:30 へ変更済み |

**18:30 は 2つの意味で使われている**: (a) Biz-Logi で 19:00 に自動で集荷を依頼する前の、予約と変更の締切（11/04 の決定）、(b) 佐川の営業所への緊急の連絡の期限（佐川）。たくまさんの指摘の「18:30 は緊急連絡の期限」は (b) で、実装の 18:30 は (a)。

| 案 | 内容 | 影響 |
|---|---|---|
| A. 18:30 のまま | 予約・自分での取消は前日 18:30 まで（11/04 の決定のとおり）。19:00 の依頼の前なので、18:30 までの取消は佐川への連絡が要らない | 実装の変更なし。規約は 18:30 |
| B. B2C だけ 17:00 | 旅行者の予約・自分での取消は前日 17:00。17:00〜18:30 は運営へ個別に相談。B2B は 18:30 のまま | B2C の判定・DB の関数（071 の後に新しい SQL 079 以降）・メールの文面・試験の変更（約 0.5〜1日）。17:00〜19:00 の B2C の取消は、まだ依頼前でも運営の手作業になる |
| C. B2B・B2C とも 17:00 | 11/04 の決定を取り消す | Biz-Logi の統合の設計（19:00 送信）と B2B の画面・案内の変更。本番前の他のセッションの作業にも影響 |

規約の原案は、締切を「受付締切」という言葉で 1か所だけに定義し、値は `【D0】` のままにした（決まれば 1行の差し替え）。**実装は変えていない。**

## D1. 集荷日の 11:00 までに荷物が預けられなかった場合

**採用した方針**: Beta では原則として請求しない。未集荷のアラートを出し、運営が状況を確認する。

| 項目 | 内容 |
|---|---|
| 請求 | しない。請求は運営が集荷を確認した後にしか作られない（`sql/074_b2c_stage5_payments.sql` の `b2c_confirm_pickup` → `b2c_claim_charges`） |
| その後に改めて集荷した場合 | 運送会社が集荷し、運営が確認すれば、通常どおり実際の個数で請求（今の実装のまま） |
| アラート | 既存の「集荷漏れの可能性」（`app/api/cron/sync-tracking/route.ts` 631行〜）が、集荷日の 18:00 以降に未集荷の区間を運営へメールする。B2C の区間も対象の状態（`issued`）で作られる（`sql/071` の確定の関数）。**ただし B2C での動作は試験していない**（02 の G1） |
| 将来 | キャンセル料（預け忘れの抑止）は Beta の後に検討。消費者契約法 9条の確認が必要（`~/JOJO/state/bondex.md` 2026-11-02 の D12） |

## D2. 配送の遅れの時の返金

**採用した方針**: 一律の返金はしない。個別に判断する。ただし法令上の責任や返金の義務は排除しない。

| 項目 | 内容 |
|---|---|
| 実装 | 自動の返金は無い。運営が理由を書いて任意の額を返金できる（`lib/b2c/refund-service.ts`・`b2c_request_refund`。請求額を上限に DB で制限） |
| 佐川の約款（飛脚宅配便） | 遅延の損害は、引渡予定日の翌日までに届かなかったことによる財産上の損害を「運賃等の範囲内」で賠償（25条4項1号）。天災・予見できない異常な交通障害などは免責（22条）。故意・重大な過失は一切の損害を賠償（25条6項） |
| 注意 | 佐川の約款の賠償の相手は**荷送人**（BondEx の送り状の依頼主は当社のコード `00007017000`）。旅行者は佐川と直接の契約が無い。旅行者への責任をどう書くかは弁護士の確認（L1・L2） |

## D3. 荷物のサイズ・重量

**採用した方針**: 佐川の正式な受託の条件に準拠する。

| 資料 | 内容 |
|---|---|
| 佐川（飛脚宅配便のページ） | 飛脚宅配便は 1個「3辺合計 160cm 以内・重量 30kg 以内」。超えるもの（260cm・50kg まで）は「飛脚ラージサイズ宅配便」（別の運賃）。260サイズ（50kg）を超えるものは送れない |
| 佐川（打合せ・マスター 198・199） | スーツケースは原則 140サイズで料金を収受。「カバー無しなら 160 扱い」ではない |
| 実装 `lib/bizlogi/pickup.ts` 117行 | Biz-Logi へはサイズの区分 `160` を送る（既定） |
| 実装 `components/b2c/booking-form.tsx` 68・124行 | 予約画面「スーツケースは 3辺の合計 160cm まで」。**重さの上限は書いていない** |
| B2B の公開ページ `lib/landing-messages.ts` 621行 | 「サイズ・重さを問わず、1個あたり均一料金」 |

**規約の原案**: 1個「3辺の合計 160cm 以内・重さ 30kg 以内」（飛脚宅配便の条件）。超える荷物は予約の前に運営へ相談。
**佐川に確認すること**: BondEx の契約で 160cm または 30kg を超えるスーツケースが来た時、受けるか・どの運賃になるか（ラージサイズの運賃を当社が負担するか）。

## D4. 送れない物と補償の対象外の物

**採用した方針**: 送れない物と、補償が制限される物を分ける。佐川の正式な規定に基づく。確認していない品目は推測で足さない。

### D4-1. 送れない物（運送会社が引き受けない物）

佐川の「飛脚宅配便・飛脚ラージサイズ宅配便 約款」6条1項7号（`https://www.sagawa-exp.co.jp/assets/pdf/stipulation/stipulation_nomal.pdf`）と、佐川の「送れないもの」のページ（`https://www.sagawa-exp.co.jp/customer/send/prohibited/`）の両方に載っている物。

| 区分 | 品目 | 出典 |
|---|---|---|
| お金・証券 | 現金、小切手、手形、株券その他の有価証券 | 約款・ページ |
| カード | クレジットカード、キャッシュカードなどのカード類 | ページ |
| 再発行が難しい書類 | パスポート、受験票、車検証、各種チケット | 約款（チケットは約款だけ）・ページ |
| 原稿・記録 | 再生できない原稿・原図・テープ・フィルム・電磁記録媒体 | 約款・ページ |
| 動物 | 犬・猫・小鳥などの動物 | 約款・ページ |
| 遺骨など | 遺骨・位牌・仏壇 | 約款・ページ |
| 武器 | 銃砲刀剣類 | 約款・ページ |
| 毒物 | 毒物・劇物 | 約款 |
| 危険品 | 火薬類その他の危険品、不潔な物など他の荷物を傷めるおそれのある物 | 約款・ページ |
| 高価な物 | 1個の価格が 30万円（税込）を超える荷物 | 約款（30万円）・ページ（税込） |
| 個人情報 | 複数の個人情報を含む物・特段の注意を要する物 | 約款・ページ |
| 法令 | 信書、法令や公序良俗に反する物、法令で移動・頒布が禁止された物、生きた病原体を含む物 | 約款・ページ |
| 大きさ | 260サイズ（50kg）を超える荷物 | ページ |

**条件つきで扱う物（ページ）**: リチウムイオン電池を内蔵した製品（パソコン・携帯電話など）、電波を出す機器（電源を切った状態に限る）。危険物（バッテリーなど）の詳細は佐川の別のページ「危険物の取り扱いについて」による（**このページはまだ確認していない**。原案には品目を書かず「運送会社の基準による」とした）。

### D4-2. 補償が制限される・対象外になる物（約款と佐川の回答）

| 内容 | 出典 |
|---|---|
| 荷物の欠陥・自然の消耗、荷物の性質による変色・さびなど、天災、予見できない異常な交通障害などによる損害 | 約款 22条 |
| 壊れやすい物・変質や腐敗しやすい物で、送り状にその旨の記載が無く運送会社が知らなかった時の、特段の注意をしなかったことによる損害 | 約款 23条3項 |
| 保護カバーの無いスーツケースの外装の傷（原則として賠償は困難）。キャスター・持ち手の破損は都度調査 | 佐川の回答（マスター 200〜202） |
| 配達（ホテルでの引渡し）の後に生じた損害 | 約款 21条2項 |
| 損傷は、引渡しの日から 14日以内に通知しないと運送会社の責任が消える | 約款 24条 |

### D4-3. BondEx からのお願い（お手元で持つ物）

予約画面・メールの今の文言「貴重品・壊れやすい物・現金・パスポートはお荷物に入れず、お手元でお持ちください（補償の対象外です）」（`lib/b2c/notify-templates.ts` 96行・`components/b2c/my-booking.tsx` 81行）。現金・パスポートは「補償の対象外」ではなく「送れない物」。文言の修正案は 02 の G4。

**前回の原案の誤り（訂正済み）**: 前回の原案の第7条に「精密機器（パソコン等）」「生鮮品など傷みやすい物」を「預けられない物」として書いたが、佐川の規定では、パソコンは条件つきで扱う物、傷みやすい物は補償が制限される物で、どちらも送れない物ではない。推測で書いたので削除した。

## D5. 規約を変えた時の既存の予約

**採用した方針**: 既存の予約には、原則として予約の時に同意した規約を適用する。法令上必要な変更は弁護士の確認を受ける。

| 項目 | 内容 |
|---|---|
| 実装 | 予約ごとに同意の版を記録している（`lib/b2c/booking-service.ts` 444行 `consent_version`、`lib/b2c/card-service.ts` 215行）。今の値は `2026-11-phase1a-draft`・`2026-11-phase1a-card-draft` |
| 足りないこと | 版ごとの規約の本文を残す仕組みが無い（02 の G7） |
| 法令 | 定型約款の変更（民法 548条の4）。お客様の利益になる変更・法令による変更を既存の予約にも適用する書き方は弁護士の確認（L10） |
