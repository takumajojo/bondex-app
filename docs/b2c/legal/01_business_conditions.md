## D1. 集荷日の 11:00 までに荷物が預けられなかった場合

**採用した方針**: Beta では原則として請求しない。未集荷のアラートを出し、運営が状況を確認する。

| 項目 | 内容 |
|---|---|
| 請求 | しない。請求は運営が集荷を確認した後にしか作られない（`sql/074_b2c_stage5_payments.sql` の `b2c_confirm_pickup` → `b2c_claim_charges`） |
| その後に改めて集荷した場合 | 運送会社が集荷し、運営が確認すれば、通常どおり実際の個数で請求（今の実装のまま） |
| アラート | 既存の「集荷漏れの可能性」（`app/api/cron/sync-tracking/route.ts` 631行〜）が、集荷日の 18:00 以降に未集荷の区間を運営へメールする。B2C の区間も対象の状態（`issued`）・代理店名 `BondEx Direct` で作られる（`sql/071`）。**2026-11-05 試験**: 旅行者の予約の区間が対象になること・一度通知した区間は二度と通知しないこと・集荷の確認が無ければ請求の行が無いことを DB で確認（`scripts/test-b2c/db/b1_legal_db.sh` の M）。定時処理を動かしてメールが届くことは、試験環境（B4・B5 と同じ）で確認する |
| 運営の手順 | `06_operations_runbook.md` の 1（未集荷 → 旅行者とホテルに確認 → 再手配か取消） |
| 将来 | キャンセル料（預け忘れの抑止）は Beta の後に検討。消費者契約法 9条の確認が必要（`~/JOJO/state/bondex.md` 2026-11-02 の D12） |

## D2. 配送の遅れの時の返金

**採用した方針**: 一律の返金はしない。個別に判断する。ただし法令上の責任や返金の義務は排除しない。

| 項目 | 内容 |
|---|---|
| 実装 | 自動の返金は無い。運営が理由を書いて任意の額を返金できる（`lib/b2c/refund-service.ts`・`b2c_request_refund`。請求額を上限に DB で制限） |
| 佐川の約款（飛脚宅配便） | 遅延の損害は、引渡予定日の翌日までに届かなかったことによる財産上の損害を「運賃等の範囲内」で賠償（25条4項1号）。天災・予見できない異常な交通障害などは免責（22条）。故意・重大な過失は一切の損害を賠償（25条6項） |
| 注意 | 佐川の約款の賠償の相手は**荷送人**（BondEx の送り状の依頼主は当社のコード `00007017000`）。旅行者は佐川と直接の契約が無い。旅行者への責任をどう書くかは弁護士の確認（L1・L2） |
| 記録 | 返金には理由（必須）と運営の本人の記録（メール・パスキー）が残る。返金の合計は請求額を超えない・同じ返金を二重に作らない（`sql/074` の `b2c_request_refund`。行のロックと返金のキー）。今回は変えていない |
| 運営の手順 | `06_operations_runbook.md` の 2（遅延の時の判断の材料と、理由の書き方） |

## D3. 荷物のサイズ・重量

**採用した方針**: 佐川の正式な受託の条件に準拠する。

| 資料 | 内容 |
|---|---|
| 佐川（飛脚宅配便のページ） | 飛脚宅配便は 1個「3辺合計 160cm 以内・重量 30kg 以内」。超えるもの（260cm・50kg まで）は「飛脚ラージサイズ宅配便」（別の運賃）。260サイズ（50kg）を超えるものは送れない |
| 佐川（打合せ・マスター 198・199） | スーツケースは原則 140サイズで料金を収受。「カバー無しなら 160 扱い」ではない |
| 実装 `lib/bizlogi/pickup.ts` 117行 | Biz-Logi へはサイズの区分 `160` を送る（既定） |
| 実装 `components/b2c/booking-form.tsx`（2026-11-05 修正） | 予約画面「1個あたり 3辺の合計 160cm 以内・30kg 以内。超える場合は、予約の前にご相談ください」（日英）。修正前は重さの上限が無かった |
| B2B の公開ページ `lib/landing-messages.ts` 621行 | 「サイズ・重さを問わず、1個あたり均一料金」（B2B は今回変えていない。B2C と食い違うが、別のサービスの表示として扱う） |

**規約の原案**: 1個「3辺の合計 160cm 以内・重さ 30kg 以内」（飛脚宅配便の条件）。超える荷物は予約の前に運営へ相談。
**佐川に確認すること（S2）**: BondEx の契約で 160cm または 30kg を超えるスーツケースが来た時、受けるか・どの運賃になるか（ラージサイズの運賃を当社が負担するか）。**確認の前は、超える荷物も同じ料金で送れるとは案内しない**（規約 第6条4項は「予約の前にご相談ください」「運送会社が引き受けなかった荷物は請求しない」だけ）。

## D4. 送れない物と補償の対象外の物

**採用した方針**: 次の 3つに分ける。佐川の正式な規定（公開の約款・公式のページ）に基づき、確認していない品目は推測で足さない。

| 区分 | 何か | 規約 |
|---|---|---|
| A. 運送会社が引き受けない物 | 下の D4-1 | 第7条1項・2項 |
| B. 条件つきで扱う物 | パソコン・リチウムイオン電池を内蔵した機器・電波を出す機器（全面の禁止にしない） | 第7条1項の「バッテリーなどの扱いは運送会社の基準による」 |
| C. 補償が制限される可能性がある物 | 下の D4-2 | 第7条3項 |

**区別すること**:
- **公開の約款と法人の契約**: ここに書いたのは佐川の公開の約款・ページ（2026-11-04 取得）。BondEx の法人の契約で別の取り決め（責任限度額など）があるかは確認していない（S1）。
- **30万円の 2つの意味**: 「1個の価格が 30万円を超える荷物は引き受けない」（約款 6条・受託の制限）と、「賠償の上限」（約款 25条・送り状に書く責任限度額）は別のもの。BondEx の送り状の責任限度額の値は未確認（S1）。規約の賠償の上限（第10条3項）は空欄のまま（L3）。
- **旅行者への補償の責任**: 佐川の賠償の相手は荷送人（当社）。当社が旅行者に負う責任の範囲は弁護士の確認が終わるまで断定しない（L1・L3）。

### D4-3. BondEx からのお願い（お手元で持つ物）

2026-11-05 に予約画面・確定のメール・予約の確認ページの文言を直した（02 の G4）。「現金・カード類・パスポートなど、送れない物は入れないでください（一覧は利用規約 第7条）。貴重品・壊れやすい物はお手元でお持ちください。」（日英）。修正前は「貴重品・壊れやすい物・現金・パスポートは…補償の対象外です」で、送れない物と補償が制限される物の区別が無かった。

**前回の原案の誤り（訂正済み）**: 前回の原案の第7条に「精密機器（パソコン等）」「生鮮品など傷みやすい物」を「預けられない物」として書いたが、佐川の規定では、パソコンは条件つきで扱う物、傷みやすい物は補償が制限される物で、どちらも送れない物ではない。推測で書いたので削除した。

## D5. 規約を変えた時の既存の予約

**採用した方針**: 既存の予約には、原則として予約の時に同意した規約を適用する。法令上必要な変更は弁護士の確認を受ける。

| 項目 | 内容 |
|---|---|
| 実装（2026-11-05） | 予約の画面の同意（規約の版・言語・日時 = `b2c_orders.terms_version`・`terms_lang`・`terms_consented_at`）と、カード登録の画面の同意（後日の請求 = `card_consent_version`・`card_consented_at`）を分けて残す。**これまではカード登録の時に `consent_version` をカードの版で上書きしていて、予約の時の規約の版が残っていなかった**（直した）。本文は版×種類×言語で `b2c_legal_documents` に残し、書き換え・削除はできない（`sql/079_b2c_legal_versions.sql`）。同意の欄の文言も本文として残す。請求の前の確認にカードの同意を足した（`no_card_consent`） |
| 残り | 公開の時に版の名前を決める（例 `2027-01-v1`）・本番で本文を登録する（`scripts/b2c-legal/register-docs.ts`）。どれも公開の承認の後 |
| 法令 | 定型約款の変更（民法 548条の4）。お客様の利益になる変更・法令による変更を既存の予約にも適用する書き方は弁護士の確認（L10） |
