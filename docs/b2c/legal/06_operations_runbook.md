# 旅行者の予約の運営の手順（B1・D1〜D3）

作成: 2026-11-05。対象: 阪急交通社向けの限定 Beta（B2C Phase 1A）。運営の画面は `/operator/b2c`。
前提: 事業条件 `01_business_conditions.md`。規約の原案 `terms_ja.md`（公開前）。
**判断に迷う時・お客様から法的な主張があった時は、その場で約束せず、たくまさんに相談する。**

## 1. 未集荷（荷物が集荷されなかった）— D1

**合図**: 集荷日の 18:00 以降に「【集荷漏れの可能性】B2C-…」のメール（`app/api/cron/sync-tracking/route.ts`）。区間ごとに 1回だけ届く。

| 順 | すること | 記録 |
|---|---|---|
| 1 | 佐川の問い合わせ番号と集荷元のホテルに、荷物の有無を確認する | 運営の画面のメモ |
| 2 | 旅行者にメールで連絡する（荷物を預けたか・今どこにあるか） | 同上 |
| 3a | **ホテルに荷物があり、旅行者がまだ送りたい** → 佐川に再集荷を手配する（翌日以降の集荷になる。お届け日が変わることを旅行者に伝え、了解を得る） | 再集荷の日・旅行者の了解 |
| 3b | **荷物が無い・旅行者が送らない** → 取消の申請（`b2c_request_cancel`）→ 佐川の確認の後に取消が確定（無料） | 取消の理由 |
| 4 | 請求は、佐川が実際に集荷し、運営が集荷を確認した後だけ（`b2c_confirm_pickup`）。集荷の確認をしなければ請求は作られない | — |

- Beta の間は、預け忘れによるキャンセル料・再集荷の手数料は取らない（D1）。
- 放置しない: 必ず 3a か 3b に進める（いつまでに進めるかの期限は未決定。たくまさんが決める）。
- 再集荷の後にもう一度「集荷漏れ」のメールは来ない（区間ごとに 1回だけ）。再集荷の日は運営が自分で追う。

## 2. 配送の遅れ — D2

一律の自動の返金はしない。運営が原因・実際の損害・運送会社の責任を確かめて、個別に判断する。

| 順 | すること |
|---|---|
| 1 | 佐川の追跡で遅れの原因を確かめる（天候・交通・災害・佐川の誤配など） |
| 2 | 旅行者に、実際に困ったこと（宿泊先で受け取れなかった・必要な物が無く買った等）を聞く。領収書などがあれば受け取る |
| 3 | 佐川の責任（約款 25条4項1号: 運賃等の範囲内／22条: 天災・予見できない異常な交通障害などは免責）を佐川に確認する |
| 4 | 返金するかと額を決める。迷う場合・旅行者が強く求める場合はたくまさんへ |
| 5 | 返金は運営の画面の「返金」から。**理由の欄に、原因・旅行者の実際の損害・佐川の回答・判断の理由を書く**（必須。後から見て判断が分かるように） |

- 返金の合計は請求額を超えられない・同じ返金は二重に作られない（DB が止める）。
- 「法令上の責任は排除しない」（規約 第8条2項）。「規約で返金しないと決まっている」とは言わない。

## 3. 160cm・30kg を超える荷物 — D3

- 佐川に扱い（受けるか・運賃）を確認するまで（S2）、**同じ料金で送れるとは言わない**。
- 予約の前に相談が来たら: 「佐川急便に確認してからお返事します」と答え、たくまさんに上げる。
- 集荷の当日に分かった場合: 佐川が引き受けなかった荷物は請求しない（規約 第6条4項）。引き受けた場合の追加の運賃をどうするかは、たくまさんが判断する。

## 4. 締切の後の相談 — D0

- 旅行者の自分での取消は前日 18:30 まで（予約の確認ページ）。その後は運営への相談。
- 18:30 の後の取消は運営の画面から行う。佐川への集荷の依頼の前なら、取消はそのまま確定する。依頼の後は「取消の申請」→ 佐川の確認の後に確定。
- 佐川の世田谷営業所への緊急の変更の連絡は 18:30 まで（別の期限。`docs/sagawa/BondEx_Sagawa_BizLogi_Master_FULL_20261103.txt` 181・182）。

## 5. 規約の版の確認（D5）

- お客様が「予約の時の規約」を求めた時: 運営が予約の `terms_version`・`terms_lang` を見て、`b2c_legal_documents` の同じ版・言語の本文を送る（版の本文は書き換えられない）。
- カード登録の時の後日の請求への同意は `card_consent_version`・`card_consented_at`。
