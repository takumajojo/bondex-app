## 照合して問題が無かったもの

| 項目 | 実装 | 規約の原案 |
|---|---|---|
| 集荷の前の取消は無料 | `sql/071`（`b2c_cancel_order`・`b2c_request_cancel`）。請求は集荷の確認の後にしか作られない | キャンセル規定 1章 |
| 集荷の依頼の後の取消は「申請」→ 佐川の確認の後に確定 | `sql/071`（`b2c_request_cancel`・`shipment_cancel_hook`） | キャンセル規定 1章 |
| 確定の前（ホテルの確認中）の取消・期限切れ・ホテルが受けない時は無料 | `sql/062`・`sql/071`（`b2c_cancel_order`）・`lib/b2c/hotel-gate.ts` | 利用規約 第2条・キャンセル規定 2章 |
| 実際に集荷した個数で請求・違う時は運営が確認 | `sql/074`（`b2c_charge_check`・`b2c_resolve_charge_hold`） | 利用規約 第5条 |
| 請求の後の個数の訂正（多い → 追加、少ない → 返金） | `sql/074`（`b2c_record_piece_correction`） | 利用規約 第5条 4項 |
| 支払ができない時の案内（失敗の時・1・3・7日後） | `lib/b2c/charge-service.ts`（`enqueueCollectionReminders`） | 利用規約 第4条 5項 |
