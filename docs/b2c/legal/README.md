## 2. 弁護士の確認が必要な事項

| 番号 | 事項 | 理由 |
|---|---|---|
| L1 | **当社の立場（取次か、運送の契約の当事者か）と、貨物利用運送事業法の登録の要否** | 旅行者から料金を受け取って配送を手配するため。立場で規約の書き方（責任の範囲）が変わる |
| L2 | **責任の制限の条項**（代理店向けの規約の「責任は料金を上限」） | 消費者契約法 8条・8条の2・10条（事業者の責任の全部の免除・故意または重大な過失の時の一部の免除は無効など）。旅行者（消費者）向けには書き直しが要る |
| L3 | **破損・紛失の補償の内容と上限** | 代理店向けの規約の「1個 30万円まで」は佐川急便の約款・回答で裏付けが取れていない。佐川急便の運送約款の責任限度額・申告の期限を確認して書く必要がある |
| L4 | 海外からの旅行者との契約に適用される法律と裁判所 | 法の適用に関する通則法 11条（消費者契約の特例）。旅行者の常居所の国の強行規定が適用されうる。「日本法・当社の所在地の裁判所」の専属の合意が有効か |
| L5 | 日本語と英語の優先 | 英語の旅行者に日本語を優先とする条項が有効か・表示の方法 |
| L6 | 特商法の表記（電話番号を「請求があれば開示」で足りるか・役務の提供の時期・申込みの撤回（クーリング・オフは通信販売に無い旨）の書き方・最終確認の画面の表示（12条の6）） | 通信販売の表示の義務。予約画面の最終確認の表示が足りているか |
| L7 | 集荷の後の請求（カードを登録し、後から請求する方式）の同意の取り方 | 後日の請求・個数による金額の変更・未払いの時の扱いの同意として十分か（同意の文は `card-step.tsx`） |
| L8 | 個人情報（旅行者の名前・メール・WhatsApp の番号・宿泊先と日付・紹介元の記録）・外国にある第三者への提供（Stripe・Supabase・Vercel・メールの送信の事業者・将来の Meta） | 今の `/legal/privacy` は代理店経由の情報を前提にしている。旅行者向けの通知・同意（個人情報保護法 27条・28条） |
| L9 | 未払いの扱い（回収不能の判断・回収の委託） | 回収の手段・期限の書き方 |

## 3. 社内で決める事項（たくまさん）

| 番号 | 事項 | いまの実装 |
|---|---|---|
| D1 | 旅行者が集荷の時刻（11:00）までに荷物を預けなかった時（佐川急便が集荷できなかった時）の料金 | 請求しない（集荷の確認が無いと請求の行が作られない） |
| D2 | 集荷の後の取消・配達の遅れの時の返金・補償 | 自動の返金・補償は無い（運営が個別に返金できる） |
| D3 | サイズ・重量の上限（佐川急便の基準: スーツケースは原則 140サイズで収受） | 予約画面で個数だけを聞いている（サイズは聞いていない） |
| D4 | 預けられない物の一覧（佐川急便の基準との照合） | 予約画面・通知は「貴重品・壊れやすい物・現金・パスポート」だけ |
| D5 | 規約の改定の時の既存の予約への適用 | 同意の版を予約ごとに記録している（`consent_version`） |

## 4. 公開の手順（法務の確認と D1〜D5 の決定の後）

1. 原案を確定し、`/legal/traveler/terms`・`/legal/traveler/cancellation`・`/legal/traveler/tokushoho`（日本語・英語）として公開する（代理店向けのページは変えない）。旅行者向けのプライバシーポリシー（L8）も同時に。
2. 予約画面の同意の文と、カード登録の画面の同意の文から各ページへリンクする。同意の版（`consent_version`）を新しい版にする。
3. 確定の通知（メール）と予約の確認のページにも規約へのリンクを入れる。
