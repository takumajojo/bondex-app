# 佐川 配達日数 (リードタイム) データ

- 取得日: 2026-10-30
- 出典: 佐川急便「配達日数検索」郵便番号検索 https://www2.sagawa-exp.co.jp/send/days/
  (POST /send/days/result/ に type=ZipCodeSearch, zip_from, zip_to を送信)
- 対象: 飛脚宅配便・飛脚ラージサイズ宅配便 (クール便ではない)
- days = 佐川の表示「発送日+N日」の N。最短お届け日 = 発送日 + N 日

## ファイル
| ファイル | 行数 | 内容 |
|---|---|---|
| zip_pairs.csv | 6,060 | 郵便番号ペア → 日数。source: national_to_tokyo (全国1,892市区町村の代表郵便番号→千代田区丸の内 1000005) / spot_to_tokyo (観光地75地点→1000005) / tourist_matrix (観光地65営業所の総当たり 4,160) |

## 調査で確定した事実
1. 日数は「発地の担当営業所 × 着地の担当営業所」で決まる。同一営業所なら郵便番号が違っても同じ日数 (8ケース検証)。office_pairs 導出時に矛盾ゼロ。
2. 行きと帰りで日数が違う組み合わせが 353/2,080組 (約17%)。例: 広島→金沢 +1日 / 金沢→広島 +2日、名古屋→広島 +2日 / 広島→名古屋 +1日。
3. 検索結果は日数のみ。時間帯 (午前中など) は表示されない。
4. 品質: 6,052回照会でエラー0。無作為30件を再照会して30件一致。

## 前提・限界
- 集荷時間帯によっては翌日発送扱いになり、さらに1日以上かかる (佐川の注記)。
- 一部離島・山間部は中継が必要で日数が変わる (例: 直島は高松営業所扱いで表示上は高松と同じ)。
- 全国データは市区町村の代表郵便番号1つ。大きな市町村は地区で担当営業所が変わる可能性 → 実ホテル郵便番号は予約時に照会 (lib/sagawa-lead-time.ts の live 照会) で補う。
- 佐川の営業所統廃合・輸送網変更で変わりうる。30日ごとに再取得する。
