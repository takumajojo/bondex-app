## Palette and geometry

- BondEx Red: `#c8102e`, from `design/voucher/voucher.css:27`, also `lib/voucher-pdf.tsx:316`. The repository definition takes priority over the brighter red visible in the supplied raster masters.
- Ink: `#16161a`, from `design/voucher/voucher.css:23`.
- White: `#FFFFFF`.
- Internal gray: `#8a8a92`, the existing CSS muted color, used for the source's suitcase ribs and voucher rules.
- Prohibition circles: center (32,32), radius 28, stroke 2. Source occlusion of the diagonal slash is retained for medication/electronics.
- Main reconstructed outline strokes: approximately 2 units; source-specific fill/outline roles and narrower interior details are retained. Scene illustrations keep their original relative line thickness when fitted to 64 units.

## QA

Open `icon-sheet.html`. Every row contains the master crop, reconstruction, and 24/32/48/64px samples. `reference/` PNGs are comparison inputs only, never embedded or referenced by the standalone SVGs. `reference/sources.json` records original image names and crop coordinates.

Automated validation: 18/18 PASS; see `validation.json`.

Checks: exact file set, XML parsing, viewBox, SVG rasterizer parsing, no raster/external/font/script dependencies, successful rendering at all four sizes, nonempty geometry, consistent major visual extent, and a padded viewport check to expose strokes outside the original viewBox. All painted geometry remains inside the 64×64 canvas. Reproduce with `node scripts/validate-official-icons.cjs` from the repository root. XML was also independently parsed with Python ElementTree.

Visual QA: the actual HTML was rendered and screenshots inspected in Chrome. All 18 cards and 107 images loaded without broken images or horizontal overflow at a 1200px viewport.

Corrections after visual inspection:
1. Added the source's white separation between the central and side figures in group.svg.
2. Replaced traced prohibition rings with common analytic circles; removed residual inner-ring traces after a second inspection.
3. Smoothed shallow turns in traced contours while retaining geometric corners.
4. Equalized reference/reconstruction comparison frames for useful side-by-side inspection.

At 24px, the complex reception/delivery scenes remain small and their fine details are not individually legible; the voucher logo and passport micro-lettering are not readable at that size. The source composition has been preserved rather than introducing alternate simplified artwork. Source-resolution limitations remain visible in some traced micro-details at enlarged sizes.

## Rebuilding

`python scripts/build-official-icons.py` requires Pillow, NumPy and OpenCV, only for authoring. Dependencies were installed in an isolated temporary environment; repository package manifests were not changed. The delivered SVGs and contact sheet require none of those libraries.

Only icon assets, QA material and the two authoring/validation scripts were added. Voucher/Hotel Staff/HOW TO SEND layouts, PDF generation, booking, QR, typography and page dimensions were not edited.

### 生成元・検証スクリプトの変更

- `build-official-icons.py`: cv2 を遅延 import (未導入時はトレース対象の既存 18 点を再生成せず保持)。既存 18 点は出力が既存ファイルと一致する場合のみ書き込み、差分があれば警告して書かない (`--rebuild-originals` で明示上書き)。`masters/` があれば追補分の比較用クロップを `reference/` に生成する (既存クロップは上書きしない)。比較シートに出典・方法・用途の注記と、白抜き版の帯色背景を追加。
- `validate-official-icons.cjs`: 期待ファイル一覧を 18 + 11 = 29 に更新。矢印は長辺 43–60 / 短辺 40 以上の別条件。白抜き版は `#FFFFFF` 以外の色を含まないこと、帯色に載せたとき白画素が実在することを追加検査。`validation.json` に group (original / extra) と missing (whatsapp.svg) を記録。
